# Artificial Intelligence Practicals – Unit 1 & Unit 2

Welcome to my **Artificial Intelligence Practical Repository**. This repository contains practical programs implemented using **Prolog** as part of the B.Tech Computer Science and Engineering (AI & ML) curriculum.

The repository covers Unit 1 – Introduction to AI and Intelligent Agents and Unit 2 – Problem Solving and Searching. It includes implementations of knowledge representation, recursion, list operations, graph searching and optimization algorithms.

## 🚀 How to Run the Programs

Follow these steps to execute the practical programs:

1. Install SWI-Prolog on your computer.
2. Download or clone this repository.
3. Open SWI-Prolog.
4. Navigate to the folder containing the practical file.
5. Load the required Prolog file.

Example:

```prolog
?- ['Practical-02-Arithmetic-Factorial-Fibonacci.pl'].
```

6. Execute the required query.

Example:

```prolog
?- factorial(5, F).
```

Output:

```text
F = 120.
```

**Note:** Load and execute each practical separately to avoid conflicts between predicates.
